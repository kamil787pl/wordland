# Marketing WordLand

Każdy post ma własny folder: `posty/RRRR-MM-DD-platforma-temat/`.

W folderze:
- `grafika.png` – gotowa grafika (Instagram: 1080×1350),
- `opis.txt` – opis posta z hashtagami,
- `zrodlo.html` (+ użyte obrazki) – źródło grafiki; zrzut: Playwright, viewport 1080×1350,
- opcjonalnie `notatki.md` – kiedy opublikowano, wyniki.

Uwaga: repo jest publiczne (GitHub Pages), więc pliki z tego folderu są dostępne w sieci. Nie zapisuj tu nic poufnego.
